# 麻将听牌计算器

一个纯静态的网页小工具：把手里剩下的牌点进去，算出**你听哪些牌、每种还剩几张**；另一种模式还能反推**该打哪张才能听牌**。

没有一个后端请求，所有计算都在你的浏览器里完成——不联网也能用，不上传任何数据。

**在线使用：<https://aibailey.github.io/majiang-ting-app/>**

## 功能

| 模式 | 你输入什么 | 它给你什么 |
|---|---|---|
| **听牌计算** | 手中剩余的 **1 / 4 / 7 / 10 / 13** 张牌 | 听哪几张牌，以及每张的「未见张数」 |
| **出牌听牌** | 摸牌后手中的 **2 / 5 / 8 / 11 / 14** 张牌 | 所有能让你进入听牌的出牌方案 |

### 为什么只收这几个张数

一副手牌 13 张，每副面子 3 张，所以合法手牌数必然是 `3n + 1`。**已经固定的吃、碰、杠不需要输入**——程序按「剩余部分能否拆成若干面子 + 一对将」来判断听牌。

### 关于「未见张数」

它只减去了你输入的手牌，**没有扣除吃碰杠、牌河和别家手里的牌**，所以是一个上界估计，不是精确概率。界面里也标注了这一点。

## 使用

全部是点按操作，没有需要记忆的命令：

- 点下方牌面板的牌 → 加入手牌
- 点手牌区的牌 → 移除
- 「清空」/「计算听牌」两个按钮切换、重置
- 误操作后 6 秒内可撤销，手牌历史保留 30 步

结果区用小牌块加角标显示每种听牌剩余张数；一行放不下会折叠成「+N」，读屏用户另有完整列表。

## 在手机上使用

它同时是一个 PWA，可以"安装"成独立应用：加到主屏幕后是全屏窗口、没有地址栏，并且**断网可用**。

- **Android（Chrome / Edge 等 Chromium 浏览器）**：地址栏会出现安装图标，或从菜单选「安装应用 / 添加到主屏幕」。注意：只有带 Google 移动服务（GMS）设备上的 Chrome 和三星浏览器才能装成真正的 WebAPK；其他浏览器通常只创建"带浏览器角标的快捷方式"，打开时仍走浏览器。
- **小米自带浏览器**等会主动弹安装提示，装完基本等同于原生应用。
- **OPPO 自带浏览器**通常不弹提示，也不做独立打包；可以在 `⋮` 菜单里找「添加到桌面」手动添加。能不能得到"没有地址栏"的效果取决于它是否读取 manifest 的 `display: standalone`。
- **iOS**：必须用 Safari → 分享 → 「添加到主屏幕」（iOS 不认 manifest 的安装流程，靠页面里的 `apple-touch-icon` 等 meta）。

安装与离线缓存都要求 **HTTPS**（或 localhost）；用 `file://` 直接打开时页面会跳过后台缓存注册，只是不能离线安装。

## 本地运行

两种方式都行：

```sh
# 1. 最简单：直接用浏览器打开 index.html（file:// 可用，但没有 Service Worker）
# 2. 需要离线缓存/安装效果时，起一个静态服务器
python -m http.server 8000     # 然后访问 http://localhost:8000/
```

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | **唯一入口**，HTML + CSS + JS 全部内联在这一个文件里 |
| `mahjong-ting-calculator.html` | 跳转页，仅用于兼容早期已按该地址安装的桌面图标 |
| `manifest.json` | PWA 清单：名称、`start_url`、`standalone`、竖屏、图标 |
| `sw.js` | Service Worker，负责离线缓存 |
| `icon-*.png`、`favicon-32.png`、`apple-touch-icon.png` | 各平台图标 |
| `tests/ting.test.cjs` | Node 原生测试，用 `vm` 把 `index.html` 里的脚本抽出来跑断言 |
| `FONT-LICENSE.txt` | 牌面 SVG 轮廓的来源与许可说明 |

## 离线机制

`sw.js` 对两类请求分别处理：

- **文档（HTML）**：网络优先，联网时总是拿到最新版；离线时回落到缓存。
- **静态资源（图标等）**：缓存优先，命中即返回。

因此改了 `index.html` 不需要动缓存版本号；只有改了跳转页或图标时，才把 `CACHE` 的版本号 +1 让缓存更新。

## 开发须知

**改功能只需要改 `index.html` 一个文件**——HTML、CSS、JS 全部内联在其中，没有构建步骤，也没有依赖。

| 你改了什么 | 需要动的文件 |
|---|---|
| 功能 / 样式 / 牌面 / 文案 | 只改 `index.html` |
| 图标（PNG） | 覆盖同名文件，并把 `sw.js` 的 `CACHE` 版本号 +1 |
| 新增或删除静态资源 | 引用处 + `sw.js` 的 `SHELL` 列表 |
| `mahjong-ting-calculator.html` | 正常开发不需要动它，它只是跳转页 |

**不要把 `index.html` 复制成第二份完整页面。** 历史上这里曾有两份 92 KB 完全相同的副本，改一处就会出现"桌面图标打开的版本"和"直接访问的版本"不一致。现在有三道防线：

1. `mahjong-ting-calculator.html` 只有约 1.4 KB，不含任何应用代码；
2. `tests/ting.test.cjs` 的断言会拒绝退化成副本——跳转页不得包含 `TILE_PATHS`、体积必须小于 `index.html` 的 1/4、`manifest.start_url` 必须指向真实存在的文件；
3. `.github/workflows/test.yml` 在每次 push 和 PR 时自动跑测试（[![测试](https://github.com/AiBailey/majiang-ting-app/actions/workflows/test.yml/badge.svg)](https://github.com/AiBailey/majiang-ting-app/actions/workflows/test.yml)）。

本地提交前跑一遍上面的[测试](#测试)，推送到 `main` 后 GitHub Pages 会自动发布，没有其他操作。

## 牌面与许可

34 张牌面不是 Unicode 麻将字符（`U+1F000` 区在手机系统字体里普遍缺字形，会显示成方块），而是预生成的 SVG 矢量路径，因此各机型渲染一致。轮廓提取自 **Noto Sans Symbols 2**，依 **SIL Open Font License 1.1** 使用，生成方法与版权声明见 [FONT-LICENSE.txt](FONT-LICENSE.txt)。

## 已知约束

- **`mahjong-ting-calculator.html` 是跳转页**，不是第二份应用。修改功能只改 `index.html`，不要把它复制回去——曾经两份 92 KB 的完整副本同时存在，改一处就会导致"桌面图标打开的版本"和"直接访问的版本"不一致。
- 「未见张数」不扣吃碰杠与牌河，见上文。
- 这是一个按 `3n+1` 手牌模型实现的听牌判定，不包含番种、役牌、特殊和牌型（如七对子以外的地区规则）等完整麻将规则。
