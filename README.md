# 麻将听牌计算器

把手里剩下的牌点进去，算出**你听哪些牌、每种还剩几张**；另一种模式能反推**该打哪张才能听牌**。

**在线使用：<https://aibailey.github.io/majiang-ting-app/>**

## 用法

先选模式，再点下方的牌加入手牌：

| 模式 | 输入手中剩余的 | 得到 |
|---|---|---|
| **听牌计算** | 1、4、7、10、13 张 | 听哪几张牌，以及每种的未见张数 |
| **出牌听牌** | 2、5、8、11、14 张 | 所有能让你进入听牌的出牌方案 |

- **吃、碰、杠不用输入**：程序按剩余部分能否拆成若干面子 + 一对将来判断。
- 点手牌区的牌可以移除；点错后 6 秒内可撤销。
- 「未见张数」只扣掉了你输入的手牌，没算吃碰杠和牌河，是个上界估计。

## 手机上使用

打开上面的网址，加到主屏幕就能当 App 用：全屏、没有地址栏、**断网也能用**。

- **Android**：Chrome / Edge 会提示「安装应用」，也可以从菜单里选「添加到主屏幕」。小米这类自带浏览器会主动弹安装提示；OPPO 这类自带浏览器通常不弹，需要在 `⋮` 菜单里手动「添加到桌面」。
- **iPhone**：用 Safari 打开 → 分享 → 「添加到主屏幕」。
- 安装和离线都需要 HTTPS，GitHub Pages 已经满足。
